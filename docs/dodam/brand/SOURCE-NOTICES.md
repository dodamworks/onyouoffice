# 브랜드 자산 출처와 기존 고지

- B 심벌은 이번 온유오피스 디자인 작업에서 만든 문서 두 장과 에이전트 구성이다. 다른 회사의 로고 파일을 넣지 않았다.
- 한글·영문 글자는 Pretendard v1.3.9 / 내부 버전 1.309의 600 굵기 outline이다. 폰트와 원문 OFL은 fonts/에 있다.
- 기존 프로젝트에도 같은 버전의 Pretendard Regular 400·Bold 700이 packages/ui/template-fonts/에 있고, NOTICE와 tools/gen-third-party-notices.mjs에 이미 고지돼 있다. 이번 디자인용 가변 WOFF2의 600 굵기를 기존 700 파일로 대체해 같은 결과라고 주장하지 않는다. 실제 앱에 새 폰트 파일을 묶을 경우 그 파일·자원 경로도 고지 목록에 맞춘다.
- AI 버튼의 말풍선 외곽은 기존 이음오피스 ai-mark.svg에서 유지했다. 기존 NOTICE는 Lucide/Feather 도형의 ISC/MIT 출처를 밝히고 있다. 원을 없애고 두 눈을 추가했어도 외곽의 기존 출처는 보존한다. archive/ai-mark-original.svg에 기존 SVG 주석이 남아 있다.
- 앱 아이콘·글자 조합 생성은 기존 tools/gen-brand-assets.mjs를 수정 없이 복사해 검증했다. 실제 프로젝트의 LICENSE·NOTICE는 변경하거나 삭제하지 않았다.

이 자료는 브랜드 디자인과 연결 구조의 검증이며, 설치본 배포나 등록상표 조사를 완료했다는 의미는 아니다.
