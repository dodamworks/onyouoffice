## 실제 앱 적용 때 연결할 지점

1. 현재 온유오피스 홈은 로고 SVG 대신 제품명을 글자로 표시한다. 원본 파일만 생성해도 홈이 자동으로 새 로고를 보여주지 않는다.
2. 새 컬러 로고에는 기존 전체 반전 CSS를 적용하지 않는다. 밝음·어둠·시스템 테마와 한글/기본 언어에 맞는 이미지 선택이 필요하다.
3. `apps/shell/build/brand/ai-mark.svg`와 `packages/ui/src/AiMark.tsx`를 함께 맞춰야 한다. 새로운 벤더 로고나 번역 문구를 추가할 필요는 없다.
4. 생성기가 쓰는 shell/docs 설치 아이콘, 여러 편집기의 `app-icon.png`, Linux 크기별 아이콘과 온보딩·업데이트 사용처를 함께 갱신해야 한다. 단독 docs 실행의 Dock 경로도 별도로 확인한다.
5. `apps/shell/src/renderer/update.html:261`에는 이미지 대체 텍스트 `IeumOffice`가 남아 있다. 새 브랜드 적용 때 이 기존 잔여 표기를 언어별 제품명으로 맞춘다. 이 로컬 점검에서는 실제 파일을 변경하지 않았다.
6. `NOTICE`·글꼴 생성 고지는 이미 Pretendard를 포함한다. 디자인용 가변 WOFF2를 실제 앱 자원으로 추가할 경우 실제 포함 파일과 고지 경로를 일치시킨다.
7. 실제 제품 파일을 바꾸는 단계에서는 해당 변경에 맞는 렌더링·테마·OS 아이콘 확인을 한다. 이번 아이콘 컨테이너 검증은 설치·서명·Dock/작업표시줄 등록 검증이 아니다.

이 항목들은 브랜드 원본의 결함과 구분한 적용 체크리스트다. 현재 단계에서 앱 파일을 바꿔 임의로 완료 처리하지 않았다.

## 검증 증거

- 기존 제품명 치환 테스트 17개와 설치/언어/정체성 테스트 20개: 총 37개 통과.
- SVG 파싱·외부 참조/스크립트/래스터 부재·한글/영문 outline·보관본 해시 확인.
- 컬러판과 단색판, 16/24/32/64px 심벌, 일곱 크기의 AI 마크를 브라우저에서 확인. AI SVG는 장식 요소이며 버튼 이름은 기존 번역 라벨을 유지한다.
- 두 눈의 `currentColor` 상속, 이미지 로딩, 브라우저 오류 및 외부 요청 부재 확인.
- 기존 생성기의 PNG 출력·Windows ICO 7개 크기·macOS ICNS 10개 항목과 알파 채널 확인.
- 제품·reference 관련 원본과 현재 Git index는 확인 전후 동일함을 검증.

기계 검증 결과와 대표 비교 이미지는 `preview/`에 있다. 전체 앱 테스트·빌드나 실제 AI 요청은 이번 범위에 필요하지 않아 실행하지 않았다.

## 자료의 기준

이 디렉터리의 BRAND-SPEC.json과 logos/가 브랜드 기준이다. native-inputs/는 기존 생성 도구에 연결할 규격을 제공한다. 실제 앱 코드와 생성 출력 파일은 이 PR에서 교체하지 않았다. 로컬 React 초안은 SVG와 도형 일치·테마 동작 검증에만 사용했고 이번 PR에는 실행 가능한 소스를 추가하지 않는다.
