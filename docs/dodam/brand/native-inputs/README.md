# 기존 생성 도구에 연결할 원본

선택한 B 심벌을 이음오피스의 기존 원본 규격에 담은 입력 파일이다. 기본 심벌 자체의 도형과 색은 변경하지 않았다.

- `app-icon.svg`, `app-icon-small.svg`: 기존 도구의 1024×1024 입력과 둥근 타일 규격. 작은 출력은 도구가 32px 이하에서 자동으로 선택한다. 옅은 타일은 아이콘 컨테이너이며 B 심벌 자체의 일부가 아니다.
- `logo-lockup.svg`: 영문·밝은 배경의 컬러 조합. 기존 1091×240 캔버스에 비례 배치했다. 생성기는 이 파일을 `genoffice-logo.svg`로 그대로 복사한다.
- `logo-lockup-dark.svg`, `logo-lockup-ko.svg`, `logo-lockup-ko-dark.svg`: 테마·언어별 같은 컬러 심벌과 글자 조합. 기존 생성기가 이 추가 파일들을 자동으로 언어·테마에 맞춰 연결해 주지는 않는다.
- `ai-mark.svg`: 말풍선 안 두 눈. 기존 `packages/ui/src/AiMark.tsx`와 같은 도형이다. 실제 UI는 React 부품을 쓰므로 SVG만 교체해도 UI가 바뀌는 것은 아니다.

기존 생성기의 **아이콘 출력과 복사 기능은 재사용**했다. 기존 `--preview`의 글자 조합 미리보기는 흑백 로고를 가정해 전체를 invert하므로, 컬러 로고 검증에는 그대로 쓰지 않는다. 이번 검증은 아이콘을 원본 도구에서 생성하고, 브랜드 가이드의 밝음·어둠 비교 이미지에서 컬러·언어·다크모드 조합을 별도로 확인했다.

실제 checkout에서 생성기를 실행하지 않았다. 실제 생성물은 무결성을 확인한 뒤 로컬 검증 자료로 보관했다. 설치본·OS 등록을 완료했다는 의미는 아니다.
