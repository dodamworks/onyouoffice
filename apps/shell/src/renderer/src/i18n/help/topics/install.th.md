# การติดตั้ง Onyou Office

[หน้าเผยแพร่ (Releases)](https://github.com/dodamworks/onyouoffice/releases/latest)

## เลือกไฟล์ให้ตรงกับเครื่องของคุณ

| แพลตฟอร์ม                               | ข้อกำหนด                             | ไฟล์                               |
| --------------------------------------- | ------------------------------------ | ---------------------------------- |
| **Windows**                             | Windows 10 ขึ้นไป, Intel/AMD 64 บิต  | `OnyouOffice-Setup-<version>.exe`  |
| **Mac (เบต้า)**, Apple Silicon          | macOS 12 ขึ้นไป, ชิป M1 หรือใหม่กว่า | `OnyouOffice-<version>-arm64.dmg`  |
| **Mac (เบต้า)**, Intel                  | macOS 12 ขึ้นไป, โปรเซสเซอร์ Intel   | `OnyouOffice-<version>-x64.dmg`    |
| **Linux (เบต้า)**, ทุกดิสทริบิวชัน      | 64 บิต (x86_64); glibc ≥ 2.35        | `OnyouOffice-<version>.AppImage`   |
| **Linux (เบต้า)**, ตระกูล Ubuntu/Debian | 64 บิต (x86_64); glibc ≥ 2.35        | `onyouoffice_<version>_amd64.deb`  |
| **Linux (เบต้า)**, Fedora/RHEL/openSUSE | 64 บิต (x86_64); glibc ≥ 2.35        | `onyouoffice-<version>.x86_64.rpm` |

## บน Windows

1. ดาวน์โหลด `OnyouOffice-Setup-<version>.exe` จากหน้าเผยแพร่
2. เปิดไฟล์นั้น ตัวติดตั้งไม่ได้ลงลายเซ็นโค้ด Windows จึงอาจแสดงหน้าต่างสีน้ำเงิน "Windows ปกป้องพีซีของคุณ" ขึ้นมาก่อน ให้เลือก **ข้อมูลเพิ่มเติม** แล้วเลือก **เรียกใช้ต่อไป** ข้อความที่เห็นจริงอาจต่างกันไปตามเวอร์ชันของ Windows
3. ทำตามขั้นตอนของตัวติดตั้งไปจนเสร็จ

ตัวติดตั้งจะวาง Onyou Office ไว้ในเมนู Start และลงทะเบียน `.docx`, `.xlsx`, `.pptx`, `.pdf` และไฟล์อื่น ๆ ดังนั้นดับเบิลคลิกที่ไฟล์ก็จะเปิดขึ้นมา

เนื่องจากตัวติดตั้งไม่ได้ลงลายเซ็น ให้เรียกใช้เฉพาะไฟล์ที่ดาวน์โหลดจากหน้าเผยแพร่ข้างต้นเท่านั้น

## เมื่อ Windows บล็อกการดาวน์โหลดหรือการติดตั้ง

### Edge แจ้งว่าไฟล์ "ไม่ค่อยมีคนดาวน์โหลด"

Microsoft Defender SmartScreen จะเตือนแบบนี้กับไฟล์ที่ยังไม่ค่อยเห็นคนดาวน์โหลด คำแนะนำของ Microsoft ในการเก็บไฟล์ไว้คือ

1. เปิดรายการดาวน์โหลดของ Edge (**Ctrl+J**) กด **…** ข้างไฟล์ แล้วเลือก **Keep**
2. ในหน้าต่างที่เปิดขึ้น ให้กด **Show more** แล้วกด **Keep anyway** ไฟล์จะถูกเก็บไว้ในโฟลเดอร์ดาวน์โหลดของคุณ

หน้าต่างนั้นยังมีปุ่มสำหรับรายงานว่าไฟล์ปลอดภัยด้วย ปุ่มนั้นเพียงเปิดหน้ารายงานของ Microsoft (`feedback.smartscreen.microsoft.com`) และไม่ได้เก็บไฟล์ไว้ ให้ปิดหน้านั้นแล้วกด **Show more** ในหน้าต่างแทน

หากหน้าต่างไม่มี **Show more** หรือไม่มี **Keep anyway**:

- บนพีซีที่โรงเรียนหรือบริษัทดูแล ผู้ดูแลระบบสามารถปิดไม่ให้ข้ามคำเตือนเหล่านี้ได้ (นโยบายของ Edge) เมื่อเป็นเช่นนั้น จะไม่มีใครบนพีซีเครื่องนั้นเก็บไฟล์ไว้ได้ ให้ขอผู้ดูแลระบบติดตั้งให้หรืออนุญาตไฟล์นั้น
- การดาวน์โหลดจากหน้าเผยแพร่ด้วยเบราว์เซอร์อื่นจะได้ไฟล์เดียวกัน

### หน้าต่าง "Windows ปกป้องพีซีของคุณ" ปรากฏขึ้น

Microsoft Defender SmartScreen จะแสดงหน้าต่างนี้ครั้งแรกที่พบตัวติดตั้งที่ไม่ได้ลงลายเซ็น กด **ข้อมูลเพิ่มเติม** แล้วปุ่ม **เรียกใช้ต่อไป** จะปรากฏขึ้น บนพีซีที่โรงเรียนหรือบริษัทดูแล การตั้งค่าของผู้ดูแลระบบอาจซ่อนปุ่มนั้นไว้ ให้สอบถามผู้ดูแลระบบ

## บน Mac (เบต้า)

ต้องใช้ macOS 12 (Monterey) ขึ้นไป รุ่น Mac ไม่มีลายเซ็นนักพัฒนาของ Apple ดังนั้นเมื่อเปิดครั้งแรก macOS จะแจ้งว่าไม่สามารถตรวจสอบได้ว่าแอปปลอดจากมัลแวร์ และจะไม่เปิดแอป คุณต้องอนุญาตหนึ่งครั้งตามด้านล่าง

1. เปิดไฟล์ dmg แล้วลาก `Onyou Office.app` ไปไว้ในโฟลเดอร์ **แอปพลิเคชัน**
2. เปิด Onyou Office จากโฟลเดอร์แอปพลิเคชัน เมื่อคำเตือนปรากฏ ให้กด **เสร็จสิ้น**
3. เปิด **การตั้งค่าระบบ ▸ ความเป็นส่วนตัวและความปลอดภัย** ใกล้ด้านล่าง ข้างบรรทัดที่บอกว่า Onyou Office ถูกบล็อก ให้กด **Open Anyway** แล้วป้อนรหัสผ่าน Mac ของคุณ ปุ่มนี้จะแสดงอยู่ประมาณหนึ่งชั่วโมงหลังจากที่คุณพยายามเปิดแอป
4. ในหน้าต่างที่ปรากฏอีกครั้ง ให้กด **เปิด** จากนั้นจะเปิดได้โดยไม่มีคำเตือน

บน macOS 12 ตำแหน่งนี้คือ **การตั้งค่าระบบ ▸ ความปลอดภัยและความเป็นส่วนตัว ▸ ทั่วไป** และปุ่มที่นั่นคือ **Open Anyway**

หาก macOS แจ้งว่าแอปไม่รองรับบน Mac เครื่องนี้ ให้ตรวจสองอย่าง:

- Mac ที่ใช้ Intel รันไฟล์สำหรับ Apple Silicon (`-arm64.dmg`) ไม่ได้ ให้ดู "โปรเซสเซอร์" ใน **เกี่ยวกับ Mac เครื่องนี้** ลบแอปที่ติดตั้งไว้ แล้วติดตั้งไฟล์ `-x64.dmg` แทน
- macOS 11 หรือเก่ากว่ารัน Onyou Office ไม่ได้ **เกี่ยวกับ Mac เครื่องนี้** ก็แสดงเวอร์ชัน macOS ด้วย

นอกจากนี้บน Mac:

- การ์ดการเชื่อมต่อ AI ไม่มีปุ่มติดตั้ง ให้ทำตามลิงก์คู่มือติดตั้งอย่างเป็นทางการบนการ์ดเพื่อติดตั้ง Claude Code หรือ Codex
- การลงชื่อเข้าใช้จะเสร็จสิ้นในเบราว์เซอร์ หากเบราว์เซอร์ขอให้วางรหัส ให้รัน `claude auth login` หรือ `codex login` ใน Terminal ด้วยตัวเอง ดู [การเชื่อมต่อการสมัครสมาชิก](help://subscription)

## บน Linux (เบต้า)

- **AppImage**: ทำให้ไฟล์รันได้ (`chmod +x OnyouOffice-<version>.AppImage`) แล้วรันไฟล์นั้น ไม่มีขั้นตอนติดตั้ง
- **deb**: ติดตั้งด้วย `sudo apt install ./onyouoffice_<version>_amd64.deb`
- **rpm**: ติดตั้งด้วย `sudo dnf install ./onyouoffice-<version>.x86_64.rpm` บน openSUSE ให้ใช้ `sudo zypper install ./onyouoffice-<version>.x86_64.rpm`

แพ็กเกจ deb และ rpm ติดตั้งไว้ที่ `/opt/Onyou Office` และลิงก์คำสั่งเทอร์มินัล `/usr/bin/onyouoffice` เช่นเดียวกับบน Mac การ์ดการเชื่อมต่อ AI ไม่มีปุ่มติดตั้ง และเมื่อการลงชื่อเข้าใช้ขอรหัส ให้รัน `claude auth login` หรือ `codex login` ในเทอร์มินัลด้วยตัวเอง

## เวอร์ชันที่คุณกำลังใช้

**การตั้งค่า ▸ เกี่ยวกับ** คือที่ที่แอปรายงานว่าคุณมีเวอร์ชันไหน ติดตามช่องทางอัปเดตไหน และโปรเจกต์นี้อยู่ที่ไหน รวมถึงระบุชื่อโปรเจกต์โอเพนซอร์สที่แอปนี้พัฒนาต่อยอดมา

## บรรทัดคำสั่งมาให้ด้วย

ทุกการติดตั้งมีคำสั่ง `onyouoffice` ที่คุยกับเอนจินตัวเดียวกับที่หน้าต่างใช้ ทั้งสองฝ่ายจึงไม่มีวันขัดแย้งกันเรื่องไฟล์ `onyouoffice install-cli` จะนำคำสั่งนี้ไปไว้ใน `PATH` ของคุณ ดู [บรรทัดคำสั่งและเอเจนต์](help://cli) ว่ามันทำอะไรได้บ้าง
